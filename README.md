### 🚀 Featured Project

#### 🌊 [WaveGuard — IoT Coastal Early-Warning System](https://github.com/shadeed2004-gif/waveguard)
Buoy-based system detecting dangerous fair-weather coastal swell surges (*Kallakkadal*) along the Kanayannur coastline, Kerala.

- **Stack:** ESP32, MPU-6050, SIM800L (GSM), Python, FastAPI, React.js, SQLite, Open-Meteo API
- **What it does:** ESP32 firmware samples IMU g-force across 20-sample windows, classifies sea state as CALM / WATCH / WARNING, transmits every 5s. A Python fusion engine cross-validates buoy readings against Open-Meteo satellite wave data.
- **Highlights:** Bilingual (English/Malayalam) React dashboard with JWT-authenticated admin console; GSM SMS alerts via SIM800L handling 2A transmission spikes with a 1000µF bulk capacitor.
- 🔗 [Live demo](https://waveguard-liart.vercel.app)
